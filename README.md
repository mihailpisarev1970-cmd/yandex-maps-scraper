# 🗺️ Yandex Maps Scraper — парсер Яндекс.Карт на Python

**Сбор базы организаций и контактов с Яндекс.Карт: название, категории, адрес, телефон, сайт, рейтинг, число отзывов и ссылка на карточку — всё в один Excel-файл.**

[![Playwright](https://img.shields.io/badge/Playwright-1.48%2B-2EAD33?logo=playwright&logoColor=white)](https://playwright.dev/python/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey.svg)]()
[![Dedup](https://img.shields.io/badge/дедупликация-по%20названию%20и%20сайту-success.svg)]()
[![Export](https://img.shields.io/badge/экспорт-Excel%20.xlsx-1F4E79.svg)]()

> **Для чего это нужно:** лидогенерация и B2B-продажи, холодные обзвоны, конкурентный анализ,
> мониторинг бизнеса в городе, наполнение CRM, геоаналитика, локальное SEO и сбор данных
> для маркетинговых исследований.

## ✨ Возможности

| Возможность | Как реализовано |
|---|---|
| 🎯 **Сбор по списку запросов** | Любое количество запросов через `;` — например, 10 районов × 20 ниш |
| 📋 **8 полей из карточки** | Название, категории, адрес, телефон, сайт, рейтинг, отзывы, ссылка |
| ☎️ **Раскрытие телефонов** | Автоматическое нажатие «Показать телефон» + извлечение из `tel:`-ссылок |
| 🚫 **Фильтр автовизиток** | Отбрасываются бесплатные `clients.site`, `business.site`, `yandex.ru` |
| 🔁 **Дедупликация** | По нормализованному названию **и** по домену сайта — с учётом уже собранных |
| ➕ **Инкрементальный сбор** | Новые запуски дописывают строки в существующий `.xlsx`, а не затирают его |
| 💾 **Промежуточные сохранения** | Excel перезаписывается каждые N записей — данные не теряются при сбое |
| 🤖 **Антибот-логика** | Случайные паузы, «человеческие» задержки, скрытие `navigator.webdriver` |
| 🛡️ **Обнаружение капчи** | Находит капчу по iframe/URL/title, ставит длинную паузу и пробует продолжить |
| 🌐 **Прокси с авторизацией** | HTTP/HTTPS-прокси (в т.ч. резидентные), проверка работоспособности до старта |
| 📊 **Excel «из коробки»** | Готовое оформление: жирная шапка, автоширина колонок, закреплённая строка |
| 📝 **Подробное логирование** | Консоль + `parser.log`; при критической ошибке — скриншот `error_trace.png` |
| ⚙️ **Полная конфигурация через `.env`** | Ничего не нужно менять в коде — только переменные окружения |

## 🚀 Установка

### Шаг 0. Требования

- **Python 3.10+** (проверено на 3.13)
- **pip**
- ~500 МБ свободного места (браузеры Playwright)
- Аккаунт не нужен — используется публичный веб-интерфейс Яндекс.Карт

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/mihailpisarev1970-cmd/yandex-maps-scraper.git
cd yandex-maps-scraper
```

### Шаг 2. Виртуальное окружение

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Windows (CMD):**
```bat
python -m venv venv
venv\Scripts\activate.bat
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4. Установка браузера Playwright (обязательно!)

```bash
playwright install chromium
```

Если браузер не скачивается (прокси/корпоративная сеть), установите системные зависимости:

```bash
playwright install --with-deps chromium
```

### Шаг 5. Создание конфигурации

Скопируйте шаблон и заполните своими значениями:

**Windows:**
```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**
```bash
cp .env.example .env
```

> ⚠️ **Файл `.env` содержит ваши секреты и уже добавлен в `.gitignore`.**
> В репозиторий он не попадёт. В репозитории лежит только `.env.example` без реальных данных.

### Шаг 6. Запуск

```bash
python main.py
```

Код возврата: `0` — успех, `1` — данных не собрано / прокси не работает, `130` — остановлено пользователем (`Ctrl+C`).


## ⚙️ Настройка

Все параметры задаются в `.env`. Полный список — в [`.env.example`](.env.example).

### Запросы

```env
# Один запрос
SEARCH_QUERY=Автосервис Санкт-Петербург

# Несколько сразу — через точку с запятой
SEARCH_QUERIES=Автосервис Санкт-Петербург;Шиномонтаж Санкт-Петербург;Автоэлектрик Москва
```

На каждый запрос собирается до `MAX_RESULTS_PER_QUERY` уникальных организаций.

### Основные параметры

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SEARCH_QUERY` | `Автосервис Санкт-Петербург` | Одиночный поисковый запрос |
| `SEARCH_QUERIES` | — | Список запросов через `;` (приоритетнее одиночного) |
| `MAX_RESULTS_PER_QUERY` | `200` | Лимит организаций на запрос |
| `MAX_RESULTS` | `0` | Общий лимит (0 — без ограничения) |
| `EXCEL_FILENAME` | `results.xlsx` | Имя выходного файла |
| `LOG_FILE` | `parser.log` | Имя файла логов |
| `HEADLESS_MODE` | `False` | `True` — без окна браузера (сервер/CI) |
| `SAVE_EVERY` | `25` | Сохранять Excel каждые N записей (0 — выключено) |

### Прокси

```env
USE_PROXY=True
PROXY_SERVER=http://host:port
PROXY_USERNAME=your_login
PROXY_PASSWORD=your_password
PROXY_CHECK_STRICT=True
```

- Схема `http://` или `https://` подставляется автоматически, если не указана.
- Перед парсингом выполняется проверка (3 попытки, 3 внешних сервиса определения IP).
- `PROXY_CHECK_STRICT=True` — остановиться при неработоспособном прокси.
- `PROXY_CHECK_STRICT=False` — продолжать, даже если проверка не прошла.

### Паузы (антибот)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BATCH_SIZE` | `25` | Карточек в «пачке» до длинной паузы |
| `BATCH_PAUSE_MIN` / `MAX` | `150` / `300` | Пауза между пачками, сек |
| `QUERY_PAUSE_MIN` / `MAX` | `60` / `180` | Пауза между запросами, сек |
| `CARD_PAUSE_MIN` / `MAX` | `1200` / `3000` | Пауза на одну карточку, мс |
| `CAPTCHA_PAUSE` | `900` | Ожидание при капче, сек |
| `MAX_RETRIES` | `3` | Повторы загрузки страницы |
| `RETRY_DELAY` | `2.0` | Задержка между повторами, сек |

> 💡 **Не уменьшайте паузы без необходимости.** Меньше задержки → больше капчи и риск блокировки.
> Если капча появляется часто — включите резидентный прокси и увеличьте паузы.

## 🕹️ Как это работает

```
main.py
  ├─ проверка прокси ................. scraper/proxy_check.py
  ├─ загрузка существующего Excel .... scraper/exporter.py
  │
  └─ parse_yandex_maps() ............. scraper/yandex_parser.py
       ├─ ФАЗА 1: сбор ссылок
       │    ├─ открыть yandex.ru/maps/?text=<запрос>
       │    ├─ закрыть cookie-баннер
       │    ├─ скроллить панель выдачи
       │    └─ вытащить нормализованные ссылки /maps/org/<slug>/<id>/
       │
       └─ ФАЗА 2: обход карточек
            ├─ проверка капчи → пауза → повтор
            ├─ переход с ретраями
            ├─ извлечение 8 полей
            ├─ раскрытие телефона («Показать телефон»)
            ├─ фильтр автовизиток
            ├─ дедупликация (название + домен)
            ├─ промежуточное сохранение каждые N записей
            └─ пауза между «пачками»
```

### Извлекаемые поля

| Поле | Источник |
|---|---|
| **Название** | `h1` карточки (`orgpage-header-view__header`, `card-title-view__title`, `[itemprop=name]`) |
| **Категории** | блоки `business-categories-view` / `rubric-list-view` + резервный JS-эвристический парсер |
| **Адрес** | `business-contacts-view__address`, `orgpage-header-view__address`, `[itemprop=address]` |
| **Телефон** | `a[href^="tel:"]`, `business-contacts-view__phone`, после клика «Показать телефон» |
| **Сайт** | `business-urls-view__link` (ссылка очищается от query/fragment) |
| **Рейтинг** | `business-summary-rating-badge-view__rating` → нормализация `4,8` → `4.8` |
| **Отзывов** | число перед «оцен…»/«отзыв…» в блоке рейтинга |
| **Ссылка** | канонический URL карточки организации |

### Дедупликация

Организация пропускается, если совпало **одно из двух**:

- **название** — приведено к нижнему регистру, сжаты пробелы, убраны кавычки/ёлочки;
- **домен сайта** — без `www.`, схемы и порта.

Проверяется и против уже собранных данных из Excel, и внутри текущего запуска.
Поэтому можно запускать парсер повторно по тем же запросам — база будет только дополняться.

## 🔧 Частые проблемы

| Проблема | Решение |
|---|---|
| `playwright: Executable doesn't exist` | Выполните `playwright install chromium` |
| `ModuleNotFoundError: No module named 'config'` | Запускайте из корня проекта: `python main.py` |
| Прокси не работает → останов | Проверьте логин/пароль и схему; для отладки поставьте `PROXY_CHECK_STRICT=False` |
| Постоянно ловит капчу | Включите `USE_PROXY`, увеличьте `BATCH_PAUSE_*` / `CARD_PAUSE_*`, снизьте `MAX_RESULTS_PER_QUERY` |
| Поля пустые (`Нет названия`, `Нет адреса`) | Яндекс изменил вёрстку — обновите селекторы в `selectors.py` |
| Телефоны не собираются | Проверьте `PHONE_BUTTON_SELECTORS` — кнопка «Показать телефон» могла измениться |
| Excel не открывается / занят | Закройте файл в Excel перед запуском |
| Парсер нашёл 0 ссылок | Попробуйте другой запрос, проверьте прокси, запустите с `HEADLESS_MODE=False` и посмотрите глазами |
| Ошибка → появился `error_trace.png` | Откройте скриншот: там видно, что было на странице в момент сбоя |

## 🧭 Адаптация под изменения вёрстки

Яндекс регулярно обновляет разметку. Все селекторы собраны в одном месте — `selectors.py`.
Один элемент описан списком: парсер перебирает варианты и берёт первый сработавший.

```python
NAME_SELECTORS = [
    'h1[class*="orgpage-header-view__header"]',
    'h1[class*="card-title-view__title"]',
    'h1[itemprop="name"]',
]
```

Если нужного поля больше нет:
1. Откройте карточку организации в браузере → DevTools → `Ctrl+Shift+C`;
2. Найдите новый селектор;
3. Добавьте его **в начало** списка в `selectors.py`.

## 🔒 Безопасность и секреты

- `.env` в `.gitignore` — реальные прокси-логины/пароли **не попадают** в репозиторий.
- В репозитории только `.env.example` с пустыми значениями.
- Если вы случайно закоммитили `.env` — смените пароль и удалите файл из индекса:
  ```bash
  git rm --cached .env
  git commit -m "chore: remove secrets"
  ```
  и почистите историю (`git filter-repo` / BFG Repo-Cleaner).
- Никогда не публикуйте скриншоты логов: `parser.log` может содержать IP, URL и данные прокси.
